# Acme Admin

Sample React + TypeScript admin app (Vite, Tailwind, shadcn-style primitives in `src/components/ui`).

```bash
npm install
npm run build   # typecheck + production build
npm test        # vitest
```

Design system: primitives live in `src/components/ui/`, tokens in `src/styles/globals.css` and `tailwind.config.js`.
